# xshawalx.github.io

Minimal personal link-in-bio homepage for Shawal (@xshawalx).

## Brand system

- Orange: `#FF6A00`
- Black: `#000000`
- Static HTML/CSS with minimal JavaScript
- Mobile-first, accessible and GitHub Pages compatible

## Updating links

Edit only `links.js` for external profile URLs and PayPal.

`PAYPAL_URL_HERE` is intentionally left as a placeholder. The homepage renders the PayPal control as disabled until a real URL is supplied.
