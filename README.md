# xshawalx.github.io

Minimal personal link-in-bio homepage for Shawal (@xshawalx).

## Visual system

The homepage now follows the softer visual language used by MacamTu:

- Background: `#0d0d0e`
- Cards: `#171717` / `#1d1d1d`
- Primary text: `#f5f5f5`
- Muted text: `#a0a0a0`
- Accent: `#ff8a1f`
- Thin translucent borders, restrained gradients and subtle hover motion
- Poppins for headings/controls and Open Sans for body copy
